# Dozer Dispatch — case study

A public case study for **Dozer Dispatch**, a voice-first shop companion that answers from your
own equipment manual in seconds — hands-free, page-cited, and field-validated by working service
techs.

- **Live product:** https://dozerdispatch.com
- **Case study (this site):** https://4websec.github.io/dozer-dispatch-showcase/
- **By:** [Karman Line AI, LLC](https://karmanline.ai) — a service-disabled veteran-owned small business

This repository holds only the curated public showcase (a single self-contained static page). It
contains **no product source code, credentials, or customer data** — the application lives in a
separate private repository. Updated as we go.

Product names and brands referenced are the property of their respective owners. Field-validation
quotes are shared with permission. The product is an early-access prototype.
